# Security

Please do not report vulnerabilities in public issues.

Use GitHub's private reporting instead: the **Security** tab of this
repository > **Report a vulnerability**. We acknowledge reports within three
working days and keep you informed until a fix is released.

A vulnerability in Falco or Falcosidekick themselves belongs upstream:
https://github.com/falcosecurity/.github/blob/main/SECURITY.md. Tell us too,
so we can ship the fixed version.

Supported: the latest release.
